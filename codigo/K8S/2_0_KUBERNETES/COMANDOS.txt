4) kubectl get pods
   kubectl get svc


5) minikube service pedidos-service


=======================================================

01 Arrancar Minikube
Esto crea y enciende el clúster Kubernetes local.

minikube start

Crea un nodo Kubernetes

Inicia kubelet y componentes del clúster

No usa Docker Desktop

=======================================================

02 Cargar tu imagen dentro del clúster
Minikube no ve las imágenes locales de Docker Desktop.

minikube image load practica5_crow_redis_mysql

Copia la imagen al runtime interno

Permite que el Deployment la use

=======================================================

03 Aplicar los YAML simplificados
Esto crea MySQL, Redis y tu microservicio dentro del clúster.

kubectl apply -f .

Crea Deployments

Crea Services

Arranca los pods

=======================================================


04 Verificar que los pods están corriendo
Asegura que MySQL, Redis y Pedidos arrancaron bien.

kubectl get pods

Debes ver 3 pods: mysql, redis, pedidos

Todos deben estar en estado Running

=======================================================


05 Abrir el servicio Pedidos
Minikube abre el NodePort automáticamente en tu navegador.

minikube service pedidos-service

Abre http://127.0.0.1:30082

Accedes a tu API igual que en Docker

=======================================================
